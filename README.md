# 📊 Data Analysis & Visualization

> **A beginner-friendly Python project designed to explore, analyze, clean, and visualize sales data through an interactive command-line application.**

---

# 📖 Introduction

**Data Analysis & Visualization** is a beginner-friendly Python project developed to provide practical experience with data analysis using Python.

This interactive command-line application allows users to load a CSV dataset, explore its contents, perform DataFrame operations, handle missing data, generate descriptive statistics, create different visualizations, and save the generated plots.

The project is designed for students who are learning Python and want to understand how Python libraries such as **Pandas** and **Matplotlib** can be used for real-world data analysis.

---

# 🎯 Project Objectives

This project aims to help beginners:

✅ Understand CSV data handling

✅ Learn how to work with Pandas DataFrames

✅ Explore and understand datasets

✅ Perform sorting and filtering operations

✅ Handle missing values

✅ Generate descriptive statistics

✅ Create different types of data visualizations

# ⚙️ Project Features

The application provides the following options:

### 1️⃣ Load Dataset

Allows the user to load a CSV dataset by entering its file path.

### 2️⃣ Explore Data

Allows users to:

- Display first 5 rows
- Display last 5 rows
- Display column names
- Display data types
- Display basic dataset information

### 3️⃣ Perform DataFrame Operations

Allows users to:

- Display dataset shape
- Display columns
- Sort data
- Filter data

### 4️⃣ Handle Missing Data

Provides options to:

- Display rows with missing values
- Fill missing values with mean
- Drop rows with missing values
- Replace missing values with a specific value

### 5️⃣ Generate Descriptive Statistics

Generates statistical information using Pandas `describe()`.

### 6️⃣ Data Visualization

The project provides six different visualization options:

- 📊 Bar Plot
- 📈 Line Plot
- 🔵 Scatter Plot
- 🥧 Pie Chart
- 📉 Histogram
- 📚 Stack Plot

### 7️⃣ Save Visualization

Allows users to save the generated visualization as an image file.

### 8️⃣ Exit

Closes the application safely.
